# Contributing

Thank you for considering contributing.

## Development Setup

Clone repository

```bash
git clone https://github.com/muhammadismail040/Customer_Churn_Prediction_System.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run backend

```bash
uvicorn src.api.app:app --reload
```

Run frontend

```bash
cd frontend
npm install
npm run dev
```
